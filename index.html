🔧 Troubleshooting Common Issues

❓ Can't Find the Download Button?

Look for a section called "Releases" or "Latest Release" on the page. The download is always attached to the newest version. Click the "Assets" or "Files" dropdown if you see one.

❓ VS Code Doesn't Recognize Copilot?

Make sure you're using VS Code 1.136 or newer. Go to Help → Check for Updates to ensure you're on the latest version. Also, try restarting VS Code completely after installation.

❓ Sign-in Not Working?

Close your browser, then click "Sign in with GitHub" again in VS Code. Ensure you're logged into your GitHub account in your default browser. If issues continue, temporarily disable your antivirus or firewall.

❓ Performance Is Slow?

Close other heavy programs. If you're using an older computer, try reducing the number of open editor tabs or restarting VS Code. The AI needs a bit of processing power to respond quickly.
